# M5StickC+を用いたガンマウントコントローラの実装
## 概要
### 前提条件
- M5StickC+はエアソフトガン本体に固定されており，遊戯者の胸を中心として上下左右方向に回転する．
- エアソフトガン及びそれに固定されたM5StickC+は回転中心から60cm程度離れた位置を運動する．
- M5StickC+の姿勢角変位と遊戯者の腕(照準)の角度変位は同一である．
  - すなわち，遊戯者の手首が固定されている. 
### 処理内容
大まかな処理は次の通りである．
1. M5StickC+で加速度，角速度，音量の二乗平均(RMS)を得る．
2. 得たデータをUDP通信でPCに送信する．
3. PCで到着したデータを基にセンサの姿勢角を推定する．
4. モニターと遊戯者の距離・モニターの大きさ・前状態からの姿勢角の変位から，カーソルの移動量を求める．
5. 求めた移動量分だけカーソルを移動し，RMSが閾値を超えていたらマウスを左クリックする．

## プログラム仕様説明
### M5StickC+上(`arduino/sendUDP.ino`)
`UdpSend()`, `mic_task()`, `getGyroAcc()`を並列処理している．
1. M5StickC+の各センサの値を取得
   - 発射判定(`mic_task()`)
     - 
   - 加速度・角速度(`getGyroAcc()`)
     - IMUからのデータを取得し，変数に格納する．
     - `M5.IMU.getGyroData()`: 角速度の取得
     - `M5.IMU.getAccelData()`: 加速度の取得
     - docs: https://docs.m5stack.com/en/api/stickc/imu
2. M5StickC+からPCへデータを送信
   - UDPパケットによる送信(`UdpSend()`)
     - port: `10503`
     - addres: **接続時に確認**
     - バイトオーダーはnative(上位バイトから順に並んでいる)
     - アラインメント無し
   - ビット列の内訳は[bool, float, float, float, float, float, float]
   - 順に[発射判定, 角速度X, 角速度Y, 角速度Z, 加速度X, 加速度Y, 加速度Z]
### PC上(`server/server.py`)
1. PCで到着したデータを読む
2. 角速度・加速度から姿勢角を計算
3. 環境変数に応じてマウスの移動距離を算出
4. 発射判定boolが真のとき，マウスを左クリック
